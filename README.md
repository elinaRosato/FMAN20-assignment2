# Image Analysis – Assignment 2

My solution to **Assignment 2** of the **Image Analysis** course (**FMAN20**) at **Lund University**, taught by K. Magnus J. Oskarsson. The full write-up, with derivations, code and figures for all seven tasks, is in [`report/report.pdf`](report/report.pdf).

## Repository structure

- `report/` — the LaTeX source (`report.tex`) and compiled PDF (`report.pdf`).
- `assets/` — figures generated by the scripts below, included in the report.
- `inl2_to_students/` — the course-provided project skeleton, containing `garment_recognition_project/` with its `datasets/` and `benchmarking/` code. `assignment2.py` in that folder holds my `im2segment` and `segment2feature`.
- `initial/filter_images/` — the six images of Task 1, extracted from the assignment PDF with `pdfimages` so the filter matching could be checked numerically.
- `inl2_2026.pdf` — the original assignment description.

## The 7 tasks

1. **Filtering** — matching five convolved images to the filters that produced them, argued from the coefficient sum, signs and symmetry (`filtering.py`).
2. **Interpolation** — linear interpolation of a 1-D signal, the triangle kernel that reproduces it, and a given piecewise-cubic kernel, with continuity and differentiability checked analytically (`interpolation.py`).
3. **Nearest neighbour and Bayes** — nearest-neighbour classification against a Gaussian MAP classifier on the same measurements (`classification.py`).
4. **Image classification** — posteriors and MAP estimate of a 2×2 binary scene seen through a noisy channel, for two noise levels (`image_classification.py`).
5. **Line classification** — MAP estimate of the position of a line in a noisy 4×4 image, with unequal priors (`line_classification.py`).
6. **Character classification** — MAP classification of a 5×3 character image under asymmetric noise (`character_classification.py`).
7. **Feature extraction** — `segment2feature`, a ten-element translation-invariant descriptor of a garment silhouette, tested with the provided benchmark (`inl2_to_students/garment_recognition_project/assignment2.py` and `garment_features.py`).

## Reproducing the figures and the report

Every script writes its figures to `assets/` and runs from the repository root:

```bash
python3 filtering.py
python3 interpolation.py
python3 classification.py
python3 image_classification.py
python3 line_classification.py
python3 character_classification.py
python3 garment_features.py
```

The feature extractor can also be run through the course benchmark directly:

```bash
cd inl2_to_students/garment_recognition_project
python3 assignment2.py
```

Requires `numpy`, `scipy` and `matplotlib`.

The report is built with `pdflatex` (or `latexmk`) from the `report/` directory:

```bash
cd report
latexmk -pdf report.tex
```
